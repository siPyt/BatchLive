5. THREE DISTINCT VALVE FAMILIES
--------------------------------
A. Blue-framed automated/isolation valve: ClassicSanitaryValve.
   ClassicValve delegates to this shared implementation.
   - Solid bowtie body, short stem, rectangular actuator block.
   - Blue rectangular frame, small blue status chip, mode lettering.
   - Canvas-colored frame interior, not a bright colored panel.
   - Green open body/actuator; black closed body/actuator.
   - Frame/chip remain blue in both states.
   - Horizontal and vertical variants rotate the mechanical symbol only.
     Captions and mode letters stay upright.
   - Vertical symbol naturally resembles the H-like reference silhouette;
     it is NOT the literal letter H in a circle.
   - Current horizontal frame: 46 x 34, stroke width 2.
   - Current vertical frame: 44 x 38, stroke width 2.
   - Default mode text is CA. This is baseline presentation, not proof
     that the simulator implements an independent device-mode variable.
   - Bound valves use ValveModule.open feedback, NOT commandedOpen.

B. Unboxed hand/manual valve: ClassicHandValve.
   - Bowtie body with stem and short handwheel crossbar.
   - No automatic blue CA frame around an ordinary manual valve.
   - Green open, black closed.
   - Horizontal/vertical variants follow the pipe.
   - If bound, clicking opens its real faceplate.
   - If unbound, it is a reference-only depiction: no fake command or
     fake live feedback. Tooltip explicitly identifies reference-only use.

C. Pneumatic/modulating control valve: ClassicControlValve.
   - Bowtie body with a short stem and semicircular/dome actuator.
   - Dome and body share green/black state color.
   - Small horizontal output-position bar beneath the symbol.
   - Green when clamped PID output > 0; black when output = 0.
   - Clamp displayed output to 0..100.
   - Current output bar: 20 units wide, 3 high; fill width = percent / 5.
   - Test 0%, 0.1% and 100%; do not round a positive output into "closed".
   - Current state represents PID OUTPUT, not measured physical travel.
     Tooltip says percent output. Do not claim physical valve feedback.
   - Clicking opens the bound PID faceplate.
   - Do not restore the old always-black, unbound ClassicBlackValve.
   - Do not substitute a pale shaded diamond without the dome.

Shared bowtie baseline:
  M-8,-6 L0,-1 L8,-6 V6 L0,1 L-8,6 Z
Stem baseline: M0,0 V-10.
Block actuator: x=-8,y=-15,width=16,height=5.
Handwheel: M-5,-10 H5.
Pneumatic dome: M-9,-10 A9,7 0 0 1 9,-10 Z.
